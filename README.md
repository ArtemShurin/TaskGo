# TaskGo

Два независимых Go-сервиса: Gateway (HTTP-шлюз) и Ledger (бизнес-логика).
Каждый сервис — отдельный Go-модуль в своей папке.

## Gateway

HTTP-сервер на порту 8080 с обработчиком `GET /ping`, возвращающим `pong`.

Запуск:

```
cd gateway
go run main.go
```

Проверка:

```
curl http://localhost:8080/ping
```

Ожидаемый ответ: `pong` со статусом `200 OK`.

## Ledger

Бизнес-логика учёта транзакций и бюджетов. При запуске:

- добавляет несколько тестовых транзакций в in-memory хранилище (пакет `store`);
- демонстрирует проверку бюджета по категории: транзакции в пределах лимита
  принимаются, превышающие лимит — отклоняются с ошибкой `budget exceeded`
  и не сохраняются;
- демонстрирует `SetBudget` для добавления нового бюджета на лету;
- загружает дополнительные бюджеты из `budgets.json` через `LoadBudgets`
  (`os.Open` + `bufio.NewReader`);
- выводит итоговый список сохранённых транзакций в консоль.

Запуск (из папки `ledger`, чтобы `budgets.json` был найден по относительному пути):

```
cd ledger
go run main.go
```
